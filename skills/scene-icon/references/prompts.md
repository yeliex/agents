# Prompt guidance

Describe the current request naturally using the relevant points below. Prioritize a clear subject, natural action, and readable silhouette.

- Explain the product action or experience when it affects the drawing, and identify the main subject, action, and necessary supporting objects.
- Describe how the reference informs outlines, color blocks, texture, and shading. Request clean, high-resolution rendering with clear edges and subtle local texture. Use the requested subject and scene.
- Describe the framing, visual center, and spacing. Treat the subject and supporting objects as one group, preserving proportions and spatial relationships. Leave clear background space above and on both sides, and preserve approved grounding or alignment.
- Specify approved subject and background colors, including relevant palette values and any requested gradient.
- Request one complete standalone square image with square outer edges.
- For edits, state what changes and which identifying features and relationships must remain.

For a transparent foreground, explicitly request true transparency and enable the tool's supported transparency parameter.
